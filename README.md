## What I build

I turn product requirements into shipped software, from user flows and interfaces to APIs, databases, tests, and deployment. My primary ecosystem is TypeScript, React, and Next.js, with professional work in React and C# / ASP.NET Core on AWS, and mobile apps in React Native and Swift.

The AI I ship is agents inside real products: they read through scoped, validated tools and wait for a person's approval before anything is saved. At work I built AI Reviewer and AI Insights for a client product.

I build with Claude Code through two software factories I made, for personal and client work. Each takes a ticket through a plan, a test-first build, review, and proof, and stops at a pull request I review.

## Engineering approach

<table>
<tr>
<td width="50%" valign="top">

### Product development

Clarify the requirement, map the user flow, build the interface and supporting system, then revise it against real behavior.

</td>
<td width="50%" valign="top">

### Full-stack implementation

Connect typed interfaces to authenticated APIs, domain rules, databases, background work, and external services.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Responsible AI integration

Validate model output, isolate providers, provide deterministic fallbacks, and require user review before generated changes affect stored data.

</td>
<td width="50%" valign="top">

### Testing and release

Use automated tests, accessibility checks, performance review, documentation, and repeatable deployment steps before release.

</td>
</tr>
</table>
